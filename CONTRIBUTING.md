# Contributing to Boot Usage Spring Boot Starter

First off, thank you for considering contributing! 

## Code of Conduct

This project adheres to a code of conduct. By participating, you are expected to uphold this code.

## How Can I Contribute?

### Reporting Bugs

- Use the GitHub issue tracker
- Include Java version, Spring Boot version, and steps to reproduce
- Provide sample code if possible

### Suggesting Enhancements

- Open an issue with the `enhancement` label
- Describe the use case and expected behavior

### Pull Requests

1. Fork the repo and create your branch from `main`
2. If you've added code, add tests
3. Ensure the test suite passes: `./gradlew test`
4. Follow the existing code style (Spring Boot conventions)
5. Write a clear commit message

## Development Setup

```bash
# Clone your fork
git clone https://github.com/YOUR_USERNAME/boot-usage.git
cd boot-usage

# Build
./gradlew build

# Run tests
./gradlew test
```

## Code Style

- Use tabs for indentation (Spring Boot style)
- Add Apache 2.0 license header to new files
- Include `@author Dhruv Rastogi` and `@since` tags
- Follow Java naming conventions
